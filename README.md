# Miksike – Pranglimine / Matmintinis (atkurtas žaidimas)

Atkurta originali **Miksike / Lefo** mintino skaičiavimo žaidimo **Pranglimine** (Lietuvoje – **Matmintinis**) programinė įranga, veikianti interneto naršyklėje.

Žaisti: **https://pijussad.github.io/matmintinis/**

## Žaidimo režimai
- Sudėtis, Atimtis, Sudėtis ir atimtis
- Daugyba, Dalyba, Daugyba ir dalyba
- Visi veiksmai
- Palyginimas (palygink dvi išraiškas: < = >)
- Reikšmių įstatymas (rask trūkstamą skaičių, pvz. `? + 3 = 12`)
- Natūralieji ir sveikieji skaičiai, režimai „Normaliai" ir „Sprintas"
- Treniruočių rezultatai (saugomi naršyklėje)

## Apie
**Miksike** (Lefo) buvo Estijos mokymosi platforma. **Pranglimine** – jos mintino skaičiavimo žaidimas, Lietuvoje žinomas kaip **Matmintinis**. Šiame projekte atkurtas žaidimo variklis ir lietuviškas sąsaja pagal interneto archyvo (Wayback Machine) kopijas ir vaizdo įrašus.
